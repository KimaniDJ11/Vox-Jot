# Vox Jot roadmap

This roadmap communicates direction, not guaranteed dates or paid-feature
promises. Shipped behavior is documented in the app and release notes; proposed
work remains subject to testing, platform constraints, licensing, and community
feedback.

## Current focus

- Make shortcut-to-text dictation reliable, fast, and easy to understand
- Improve first-run permissions, model selection, and recovery guidance
- Keep core recording and transcription local by default
- Strengthen correction learning, Phrase Keys, and app-aware Dictation Modes
- Make downloads resumable, cancellable, integrity-checked, and clearly licensed
- Publish reproducible build, testing, security, and contribution documentation
- Establish a healthy open-source issue and discussion workflow

## Next

- Measure the opt-in path from first launch to first successful dictation and
  seven-day return without collecting dictated content
- Improve accessibility, keyboard navigation, focus visibility, and status
  feedback across the app
- Reduce startup, recording-start, stop-to-text, and paste latency where measured
- Expand tests and community-supported source builds on Windows and Linux
- Improve official Mac download, update, and support discoverability

## Later, when demand is proven

- Team deployment and configuration tools
- Paid setup, priority support, and custom workflow services
- Additional official platform builds where sustainable signing and testing exist
- Commercial integrations that do not weaken the local-first core experience

## What will not be treated as shipped

- Placeholder or disabled UI
- Mock-only or developer-manual feature paths
- Smoke-test results presented as ranked benchmarks
- Models without a verified app-managed install and license path
- Draft launch pages, release notes, or funding offers that are not publicly live

Suggest priorities in [GitHub Discussions](https://github.com/KimaniDJ11/Vox-Jot/discussions).
