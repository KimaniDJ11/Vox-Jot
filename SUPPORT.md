# Vox Jot support

## Using the official Mac build

Start with the [support page](https://www.iriedinamik.org/voxjot/support/) for
installation, permissions, models, updates, and common troubleshooting.

For a reproducible app defect, open a
[GitHub bug report](https://github.com/KimaniDJ11/Vox-Jot/issues/new/choose).
Remove recordings, transcripts, API keys, local file paths, and other personal
information before attaching logs.

Use [GitHub Discussions](https://github.com/KimaniDJ11/Vox-Jot/discussions) for
questions, workflow ideas, feedback, and feature proposals.

## Self-built and modified versions

Community members may help with source builds, but Irie Dinamik cannot guarantee
support for modified binaries, unofficial packages, downstream forks, or local
toolchain problems. Always state whether you are running the official notarized
build, an unmodified self-build, or a fork.

## Security and privacy reports

Do not post vulnerabilities or exposed secrets publicly. Follow
[SECURITY.md](SECURITY.md).

## Paid help

The pay-what-you-want download supports continued development. Organizations or
individuals needing installation help, workflow setup, customization, or
commercial support can contact Irie Dinamik through the
[website](https://www.iriedinamik.org/contact/).
