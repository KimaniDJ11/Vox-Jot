## Material faults corrected

- Twelve newly registered commands were absent from Tauri's app-command permission list. A full frontend test exposed the problem; the exact commands are now allowed without widening permissions to a wildcard.
- Automatic selection probing used Copy, which can have side effects in applications such as terminals. The automatic macOS path is now passive, snapshots the active process, and fails safely when selection cannot be read.
- A delayed selection result could affect a different recording, and a stop-time wait increased latency. Results are bound to one run and late/duplicate results are rejected without adding a stop wait.
- “ASR hints used” was true for unsupported/streaming engines. It now comes from the actual engine execution.
- Lowercasing Unicode before computing edit byte offsets could invalidate slices. Offsets now remain in the original string.
- Protected Phrase Key values could bypass the size bound or be duplicated by a model. Final restored size and exact-one-slot checks now protect both cases.
- Local-provider detection accepted URL-prefix lookalikes. Backend and UI now parse the actual HTTP(S) host and permit only loopback hosts.
- Markdown retries could run twice, remain pending after interruption, or overwrite an existing edited note. Claims are atomic, interrupted jobs become retryable failures, and writes refuse to clobber different content.
- Selecting the export folder again did not repair a failed row's old bookmark. Retry/reveal can now use renewed authorization for the same saved destination.
- “Final” exports could differ from what was delivered. Successful pasted text now takes priority over earlier refined text.

## Latency and UX assessment

Normal recording uses the existing default acoustics. Automatic selection is opt-in and runs only after capture starts; an unfinished probe does not add a stop-time wait. Decoder context uses existing cache and skips contention. Markdown writes and folder retry work are outside the dictation delivery path. Ordinary dictation avoids additional segment-vector conversion when no retraction command is present. Acoustic settings recreation runs on a worker.

These are code-level safeguards, **not measured proof of unchanged end-to-end latency**. Quiet's signal processing and ASR prompt effects require real recordings and comparative measurements. Profile changes themselves can briefly reconfigure the microphone; active capture is protected.

UX guardrails influenced the corrections: existing components and navigation were retained, status/error text is visible, keyboard focus and labels are preserved, normal text uses the project's readable tokens, and edit mode has text/glyph cues rather than color alone. No actual-size installed-app contrast/layout measurement is claimed.

For the Swift writer, `.atomic` and `.withoutOverwriting` were not combined; Swift Foundation documents a crash/unsupported combination in its [upstream issue](https://github.com/swiftlang/swift-foundation/issues/1098). The bridge instead writes a temporary file and uses the SDK's exclusive rename operation.
