This package is prepared for publication only after the repository is public,
the release-asset audit is clean, and the official download path passes the
distribution gate.

## Core positioning

**One-line promise:** Press a shortcut, speak naturally, and put locally
transcribed text where your cursor already is.

**Proof points:**

- Free, open-source MIT source
- Signed and notarized Apple Silicon app
- Core transcription runs locally by default
- No account or checkout required
- Optional paid support funds continued development; it does not unlock a
  different build

## GitHub launch announcement

### Title

Vox Jot is now open source: local-first dictation for macOS

### Body

Vox Jot turns a keyboard shortcut and your voice into text at the current
cursor. The core path runs locally by default on Apple Silicon Macs.

Today the source is public under the MIT license, and the signed/notarized Mac
build is a free direct download—no account and no checkout required.

I originally tried pay-what-you-want distribution through Gumroad. It produced
four free checkouts, no paid sales, and too little real usage feedback. Opening
the project is a deliberate reset: reduce friction, make the implementation
inspectable, and learn from actual users and contributors.

The first thing I need is not stars. It is evidence from people who try the
core loop: does shortcut → speech → text work reliably in the Mac apps where
you write?

Please report reproducible issues using the issue form. Never attach private
audio or transcripts unless you intentionally choose to share them.

- Product and free download: `https://www.iriedinamik.org/voxjot/`
- Source: `https://github.com/KimaniDJ11/Vox-Jot`
- Support: `https://www.iriedinamik.org/voxjot/support/`

Optional Gumroad contributions fund signing, hosting, and continued work but do
not unlock a different app build.

## First-week operating cadence

### Daily

- Read new issues and Discussions; reproduce before labeling a defect fixed.
- Query aggregate website events by day, event, and channel.
- Check R2 installer transfer metrics, Gumroad support sales, GitHub traffic,
  stars, forks, clones, and opt-in first-party usage-event counts.
- Respond to blocked setup reports within one business day.
- Never infer an install from a click or an active user from a download.

### Milestones

| Funnel stage       | First proof target                                                                        |
| ------------------ | ----------------------------------------------------------------------------------------- |
| Product interest   | 100 real product-page views                                                               |
| Download intent    | 20 download clicks                                                                        |
| Installer transfer | 10 completed R2 DMG transfers                                                             |
| Activation         | 10 opt-in `first_dictation_success` events or 10 independently confirmed successful users |
| Community          | 5 substantive issues/discussions from non-maintainers                                     |
| Support revenue    | First voluntary paid Gumroad contribution                                                 |

These are learning thresholds, not vanity-score promises. Revisit the product
or positioning if page views arrive but download intent stays below 10%, and
prioritize setup/reliability if downloads do not become successful dictations.
