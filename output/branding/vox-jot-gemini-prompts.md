# Vox Jot image prompts

Use these with Gemini, Imagen, Midjourney, or another image model when you want a more polished pass after choosing a direction.

## Direction A: Quiet Wave

```text
Design a premium app logo and app icon for a desktop dictation app called "Vox Jot".

Brand traits:
- private
- local-first
- calm
- trustworthy
- practical
- lightweight

Concept:
- a voice waveform that also feels like a handwritten jot or note stroke
- not a generic microphone logo
- should communicate spoken words becoming clean text

Visual direction:
- rounded-square app icon
- palette led by deep cobalt blue, warm cream, and a small copper accent
- clean vector look
- soft but confident geometry
- modern desktop productivity app, not gaming, not cartoon mascot
- subtle depth, no glossy 2010 effects

Deliverables in one composition:
- icon-only mark
- horizontal wordmark reading Vox Jot
- dark and light background variants

Constraints:
- no glove mascot
- no headphones
- no photorealism
- no clutter
- no tiny details that disappear at 32px
- keep it simple enough to trace as SVG later
```

## Direction B: Scribe Loop

```text
Create several logo explorations and app icon concepts for "Vox Jot", a private offline speech-to-text app.

Core idea:
- one flowing stroke that suggests microphone + page + jotting motion
- expressive but still clean and highly legible

Mood:
- human
- modern
- slightly creative
- premium utility software

Look:
- vector brand design
- rounded forms
- palette of dark purple, soft violet, warm off-white, and a touch of muted coral
- designed for macOS app icon, Windows icon, website header, and tray icon

Include:
- 4 distinct variations in the same family
- icon-only mark
- wordmark with "Vox Jot"
- lockup on light background and dark background

Avoid:
- generic AI sparkles everywhere
- childish mascots
- overly futuristic cyberpunk styling
- dense linework
- gradients that overpower the mark
```

## Direction C: Signal Seal

```text
Design a logo system and app icon for "Vox Jot", an offline local transcription app focused on privacy and trustworthy everyday dictation.

Concept:
- protected voice signal inside a simple seal, shield, or badge form
- voice becomes text while staying on-device

Style:
- clean vector branding
- elegant and calm
- more trust-forward than playful
- suitable for accessibility software and productivity tools

Color palette:
- sage green, warm cream, dark forest ink, with optional copper accent

Show:
- square app icon
- icon on cream background
- icon on dark background
- wordmark reading Vox Jot in a strong sans-serif

Hard constraints:
- not corporate cybersecurity cliche
- not a police badge
- not a lock icon by itself
- keep shapes friendly and balanced
- must still read clearly at favicon size
```

## Direction D: Midnight Orbit

```text
Create a distinctive product-brand logo and app icon for "Vox Jot".

Product story:
- offline speech-to-text
- fast desktop utility
- works across apps
- private voice dictation

Concept:
- a compact VJ or voice-note monogram with orbital signal arcs
- should feel like serious software, not a toy

Visual system:
- dark midnight background
- violet and indigo signal arcs
- warm off-white lettering
- subtle copper accent if needed
- strong, simple geometry that can become SVG assets later

Output:
- polished app icon
- icon-only monochrome variant
- horizontal wordmark
- splash/hero presentation mockup

Avoid:
- planet logos that look like astronomy apps
- generic microphone silhouette as the whole idea
- unnecessary 3D chrome or metallic effects
- unreadable tiny details
```

## Universal refinement prompt

```text
Refine this concept to feel more like a premium productivity app for macOS and desktop, with cleaner geometry, stronger icon readability at 32px, fewer decorative details, and a more ownable silhouette.
```
